# ITMO Merch Bot — документация

## 1. Назначение

Бот позволяет купить мерч Университета ИТМО, не выходя из Telegram:
выбрать товар в каталоге, оплатить звёздами Telegram, посмотреть свои
заказы и написать в поддержку.

## 2. Архитектура

Проект состоит из двух частей.

**Сайт-каталог (`webapp/`)** — статическая страница на GitHub Pages.
Telegram открывает её внутри приложения как Mini App. Сайт читает
`products.json`, показывает товары, хранит корзину и по кнопке «Оплатить»
отправляет боту корзину методом `Telegram.WebApp.sendData`.

**Бот (`bot/`, `database/`)** — программа на Python (aiogram 3). Получает
корзину, пересчитывает сумму по ценам из своей базы (защита от подмены цены),
создаёт заказ и выставляет счёт в звёздах (валюта `XTR`).

### Путь заказа

1. Кнопка «🛒 Сделать заказ» открывает сайт.
2. Пользователь добавляет товары и нажимает «Оплатить».
3. Бот получает `web_app_data`, создаёт неоплаченный заказ, отправляет счёт.
4. Telegram присылает `pre_checkout_query` — бот проверяет заказ и отвечает `ok`.
5. После оплаты приходит `successful_payment` — заказ отмечается оплаченным,
   администратор получает уведомление.

## 3. База данных (SQLite, файл `shop.db`)

| Таблица | Поля | Назначение |
|---|---|---|
| products | id, title, description, price, image | Товары (загружаются из products.json) |
| orders | id, user_id, items (JSON), is_paid, charge_id, created_at | Заказы |
| tickets | id, user_id, text, admin_message_id | Обращения в поддержку |

## 4. Классы

- `BaseRepository` — абстрактный родительский класс: подключение к базе,
  выполнение запросов, создание таблицы.
- `ProductRepository`, `OrderRepository`, `SupportRepository` — наследники,
  каждый работает со своей таблицей.
- `Product`, `Order`, `OrderItem` — модели данных (dataclass).
- `IsAdmin` — наследник `BaseFilter` из aiogram, пропускает только администратора.
- `SupportForm` — наследник `StatesGroup`, состояние «пишу в поддержку».
- `Config` — настройки проекта.

## 5. Техподдержка

Сообщение пользователя сохраняется в `tickets` и пересылается администратору.
Бот запоминает id этого сообщения. Когда администратор отвечает на него
(reply), бот находит автора и пересылает ему ответ.

## 6. Как добавить товар

Добавьте объект в `webapp/products.json` и картинку в `webapp/images/`,
сделайте push (сайт обновится сам) и перезапустите бота.

## 7. Работа 24/7

Сейчас бот работает, пока запущен `python main.py` на компьютере. Чтобы он
работал всегда, его нужно разместить на сервере (VPS): арендовать сервер
с Linux, скопировать проект, установить зависимости и создать службу
systemd, которая запускает бота при старте сервера и перезапускает при сбое.

## 8. Оплата картой через ЮKassa (не реализована)

Вместо звёзд можно принимать рубли: подключить ЮKassa в @BotFather
(*Payments*), получить `provider_token` и передавать в `send_invoice`
параметры `provider_token=...`, `currency="RUB"`, а цену — в копейках.
